# Ravi Sharma — Video Editor Portfolio

Production-ready personal portfolio for Ravi Sharma.

## Stack
- React + TypeScript + Vite
- Tailwind CSS
- Lucide React
- Cloudinary for portfolio video delivery

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
Push the project to GitHub and import the repository into Vercel. Vercel will build with `npm run build` and serve `dist`.

## Portfolio media
All six portfolio videos are already configured as Cloudinary URLs in `src/data/portfolio.ts`. No large video files need to be stored in GitHub.

Social links are also already configured there.
